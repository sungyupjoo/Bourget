# Bourget

> "생각하는 대로 살지 않으면, 사는 대로 생각하게 된다." (Paul Bourget)

Bourget은 무심코 여는 앱이나 웹사이트 앞에서 잠시 멈추고 생각할 수 있도록 확인 창을 띄우는 Android 앱입니다. 사용을 막거나 시간을 제한하지 않으며, 계속 사용할지는 사용자가 정합니다.

## 기능

- **앱 규칙**: 선택한 앱이 실행되면 화면을 덮는 확인 창을 띄웁니다. "돌아가기"는 홈 화면으로 이동합니다.
- **웹사이트 규칙**: 지원 브라우저에서 등록한 도메인(하위 도메인 포함)에 들어가면 확인 창을 띄웁니다. "돌아가기"는 브라우저 뒤로가기입니다.
  - 지원 브라우저: Chrome, 삼성 인터넷 (실기기에서 주소창 노드를 확인한 브라우저만 지원합니다)
  - 주소창의 주소를 확인할 수 없으면(주소 입력 중, 지원하지 않는 브라우저 등) 동작하지 않습니다.
- 규칙마다 켜기/끄기와 동작을 고를 수 있습니다: 확인 창, 또는 미리 고른 다른 앱 실행. Bourget이 실행한 앱은 몇 초 동안 규칙에서 제외되어 서로를 계속 여는 일이 없습니다.
- 확인 창 문구는 사용자가 정합니다. 기본값은 "정말 {이름}을(를) 열고 싶으신가요?"이고 `{이름}`에 앱 이름이나 도메인이 들어갑니다.
- 규칙마다 30초 쿨다운이 있고, 같은 앱이나 같은 사이트 안에서의 이동에는 다시 개입하지 않습니다.

## 개인정보 보호

- 인터넷 권한이 없습니다. 광고, 분석, 오류 보고 도구를 쓰지 않습니다.
- 접근성 서비스로 앞에 보이는 앱의 패키지 이름과, 지원 브라우저 주소창의 주소만 읽습니다. 웹페이지 내용은 읽지 않습니다.
- 앱 사용 내역과 방문 기록을 저장하지 않습니다. 사용자가 만든 규칙만 기기에 저장하며, 클라우드 백업에서도 제외합니다.
- 앱 안의 고지를 보고 동의하기 전에는 접근성 서비스가 켜져 있어도 아무것도 확인하지 않습니다.

### 개인정보 처리방침

- 문서: [PRIVACY.md](PRIVACY.md) (앱 안의 처리방침과 같은 내용)

  - 저장소가 공개 상태여야 하고, `PRIVACY.md`가 `main` 브랜치에 있어야 접근할 수 있습니다.

## 빌드

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # 단위 테스트
./gradlew lintDebug            # Android Lint
```

설치 후 앱을 열어 고지에 동의하고, 시스템 접근성 설정에서 "Bourget 앱 실행 알림"을 켭니다. 직접 설치한 앱은 Android 13 이상에서 "제한된 설정" 해제가 필요할 수 있습니다.

## Google Play 제출 자료

Bourget은 장애인 보조 도구가 아니므로 `isAccessibilityTool`을 선언하지 않으며, Play의 접근성 API 정책에 따라 아래 자료가 필요합니다.

### 접근성 API 신고서 초안

> Bourget은 사용자가 고른 앱이나 웹사이트를 열 때 확인 창을 띄우거나 사용자가 미리 고른 다른 앱을 열어, 습관적인 사용을 스스로 알아차리게 돕는 앱입니다. 접근성 API로 (1) 창이 바뀔 때 앞에 보이는 앱의 패키지 이름과 (2) Chrome과 삼성 인터넷 주소창 노드의 텍스트만 읽고, 사용자의 규칙과 비교하는 데만 사용합니다. 읽은 정보는 저장하거나 전송하지 않습니다. 앱에는 인터넷 권한이 없습니다. 사용자는 앱 안의 고지를 보고 명시적으로 동의해야 하며, 동의 전에는 서비스가 아무것도 처리하지 않습니다.

### 시연 영상 구성

1. 앱 실행 → 소개와 추천 앱 선택 → 접근성 고지와 개인정보 처리방침 확인 → "동의하고 접근성 설정 열기"
2. 시스템 접근성 설정에서 서비스 켜기 → 앱으로 돌아와 규칙 목록 확인
3. 앱 규칙 추가 → 그 앱을 열 때 확인 창 표시
4. 규칙 동작을 "다른 앱 실행"으로 바꾸기 → 그 앱을 열 때 고른 앱이 열림
5. 웹사이트 규칙 추가 → Chrome에서 해당 사이트를 열 때 확인 창 표시, "돌아가기"로 이전 페이지 이동

### 데이터 보안 양식

모든 처리가 기기 안에서 이루어지고 기기 밖으로 전송되지 않으므로 "수집하는 데이터 없음", "공유하는 데이터 없음"으로 신고합니다.

### 접근 범위가 바뀔 때

서비스가 읽거나 저장하는 정보가 바뀌면 `DISCLOSURE_VERSION`(`TargetAppsStore.kt`)을 올리고, 앱 안의 고지, `PRIVACY.md`, 위 신고서와 데이터 보안 양식을 함께 고칩니다. 자세한 개발 규칙은 [AGENTS.md](AGENTS.md)에 있습니다.
